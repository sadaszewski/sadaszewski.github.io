What this build understands

from! module import name [as alias]
Compile-time import of one macro, visible in the enclosing scope from that line on. import! module.name as alias also works.
name! args [import x] [as y]: body
Statement macro. Arguments, clauses and body are all optional. In the body, "red" = 1 is allowed.
name!
next statement
Sibling macro: it receives the statement that follows it.
value = name!(args)
Expression macro. A line that starts with name! is always a statement macro, as the PEP specifies; wrap it in parentheses to use an expression macro there.
ast.MacroStmt · ast.MacroExpr · ast.StmtExpr
The new tree nodes (also as macro_stmt, macro_expr, stmt_expr).
macros.macro_processor(kind, version, *parts)
Decorator for processors. Also macros.new_name(node) for hygienic names and macros.expand(tree).
